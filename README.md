## ❓ 科学上网与机场选择常见 FAQ

### Q1：专线机场（IEPL/IPLC）和普通公网中转有什么本质区别？
> **答**：普通公网中转国内入口到国外出口走的是公网国际出海通道，敏感时期极易遭遇 GFW 丢包、QoS 降速甚至阻断；而 **IEPL/IPLC 专线**走的是大厂租赁的跨境点对点内网物理海底光缆，不经由公网防火墙，即使国庆、春节等特殊敏感期，也能保持 **0% 丢包** 与毫秒级延迟稳定性。推荐追求全天候不掉线的用户首选 [闪电鼠](https://jcleida.com/reviews/shandianshu.html)。

### Q2：为什么建议优先购买月付，而不是直接冲动三年付？
> **答**：即使是运营 5 年的老牌机场，国际链路和机房也可能面临不可抗力波动。购买月付或季付可以牢牢掌握主动权；若用量不固定，可优先选 [大佬云](https://jcleida.com/reviews/dalaoyun.html) 或 [云界线](https://jcleida.com/reviews/yunjiexian.html) 的**一次性不过期流量包**，长期备用也不会月底清零浪费。

### Q3：为什么连接了节点后，访问国内应用（如微信、淘宝、网易云）变慢了？
> **答**：这是因为客户端误开成了**全局代理 (Global)**。日常使用请务必在客户端设置为**规则模式 (Rule)**，配合 GeoSite / GeoIP 规则分流，国内网站直接走本地宽带高速直连，仅境外受阻网站走代理节点。详见：[小火箭规则分流模式详解](https://jcleida.com/articles/shadowrocket-rules.html)。

### Q4：专属 7 折优惠码如何生效？续费能用吗？
> **答**：在各品牌官网结算台的「优惠券 / 促销代码」输入框填入专属优惠码（如闪电鼠填 `sd88`，大佬云填 `dly88`，神行加速填 `sx0077`，云界线填 `yjx888`，榴莲云填 `ll88`，环球梯填 `HQ66`），点击兑换即可立减 30%。建议在首次购买时选择稍长周期（如季付或年付），以锁定最大的优惠折扣总额。
